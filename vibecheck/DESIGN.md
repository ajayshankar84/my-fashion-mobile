# VibeCheck Design System

## Color Palette

| Token | Hex | Usage |
| :--- | :--- | :--- |
| **Primary (Vibe)** | `#7E3AF2` | Main brand color, buttons, active states |
| **Secondary** | `#0694A2` | Secondary actions, filters |
| **Dark (Onyx)** | `#111827` | Backgrounds, primary text in light mode |
| **Light (Snow)** | `#F9FAFB` | Backgrounds, primary text in dark mode |
| **Accent (Trend)** | `#FF5A1F` | Sale badges, notifications, highlights |

## Typography
- **Font Family:** `Inter`, sans-serif (Clean, readable for fashion product names)
- **Headings:** Bold (700), `Inter`
- **Body:** Regular (400), `Inter`

## Spacing (8pt Grid)
- **XS:** `4px`
- **SM:** `8px`
- **MD:** `16px`
- **LG:** `24px`
- **XL:** `32px`
- **XXL:** `48px`

## Component Properties
- **Border Radius:** `12px` (Modern, softened corners)
- **Elevation:** `0 4px 6px -1px rgba(0, 0, 0, 0.1)`

## Iconography
- Style: Outline for inactive, Solid for active
- Weight: Medium

## Interaction States
- **Hover:** 10% brightness increase
- **Active/Pressed:** 10% brightness decrease
- **Disabled:** 40% opacity
